{"answer":"“Lua monitors” means Hyprland’s Lua-based monitor configuration, introduced as the preferred configuration format in Hyprland 0.55. The core form is `hl.monitor({ output = \"DP-1\", mode = \"1920x1080@144\", position = \"0x0\", scale = 1 })`; use `hyprctl monitors all` to discover output names and modes. In Omarchy, these rules normally live in `~/.config/hypr/monitors.lua`; an empty `output = \"\"` acts as a fallback for unspecified displays. Be careful with Omarchy’s current catch-all scale variable on multi-monitor systems: its Display panel may persist one monitor’s scale globally, so explicit per-output rules are safer when you need stable independent scales.","sources":[{"title":"Hyprland Wiki — Monitors","url":"https://wiki.hypr.land/0.55.0/Configuring/Basics/Monitors/"},{"title":"Hyprland official Lua example","url":"https://github.com/hyprwm/Hyprland/blob/main/example/hyprland.lua"},{"title":"Omarchy monitor scaling issue","url":"https://github.com/basecamp/omarchy/issues/6673"}]}
